# Decisions

The builder's log. Newest first.

Nothing reaches this file automatically. Entries are drafted into
`docs/DECISIONS.draft.md` — by the `/log` skill or the `SessionEnd` hook — and
promoted here only through `/log-review`, one at a time, in the user's own
wording, with every `INFERRED` line resolved first.

An entry here means a human read it and said keep.
